# C++ Operating System Job Scheduler

A C++ simulation of an operating system job scheduler
using a priority queue implemented with a heap.

## Features
- Schedules jobs using priority
- Simulates job processing over CPU cycles
- Tracks completed and incomplete simulations
- Calculates performance statistics

## Technologies
- C++
- Priority Queues
- Binary Heaps
- Data Structures and Algorithms

## How to Run
cd PriorityQueue
g++ -std=c++17 Lab12_Main.cpp Job.cpp -o lab12
./lab12
